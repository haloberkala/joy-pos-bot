┌──────────────────────────────────────────────────────────────────────────────┐
│ 1. ICON MATA (TOGGLE VISIBILITY)                                            │
└──────────────────────────────────────────────────────────────────────────────┘

   LOKASI: Di dalam input Password (kanan)
   
   ┌─────────────────────────────────────────┐
   │ Password *                              │
   │ ┌────────────────────────────────┐ 👁️  │
   │ │ ••••••••••                     │ │   │
   │ └────────────────────────────────┘     │
   │ ℹ️ Password untuk login (min 6 karakter)│
   └─────────────────────────────────────────┘
        ↑                              ↑
     Input field                    Icon Eye
     (type="password")              (clickable)

   ICON:
   👁️  Eye      - Password tersembunyi (default)
   👁️‍🗨️ EyeOff  - Password terlihat

   BEHAVIOR:
   ✅ Clickable button
   ✅ Hover effect (abu-abu → hitam)
   ✅ Smooth transition
   ✅ tabIndex={-1} (skip tab navigation)

┌──────────────────────────────────────────────────────────────────────────────┐
│ 2. LOGIKA SHOW/HIDE                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

   STATE MANAGEMENT:
   ┌─────────────────────────────────────────┐
   │ const [showPassword, setShowPassword]   │
   │       = useState(false);                │
   │                                         │
   │ Default: false (hidden)                 │
   └─────────────────────────────────────────┘

   TOGGLE LOGIC:
   ┌─────────────────────────────────────────┐
   │ onClick={() => setShowPassword(!show)}  │
   │                                         │
   │ false → true  (hidden → visible)        │
   │ true  → false (visible → hidden)        │
   └─────────────────────────────────────────┘

   INPUT TYPE:
   ┌─────────────────────────────────────────┐
   │ type={showPassword ? "text" : "password"}│
   │                                         │
   │ false → type="password" (••••)          │
   │ true  → type="text" (rahasia123)        │
   └─────────────────────────────────────────┘
