│ TECHNICAL IMPLEMENTATION                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

   CREATE EMPLOYEE:
   ┌─────────────────────────────────────────┐
   │ 1. Create Supabase Auth User           │
   │    - Email: username@internal.pos      │
   │    - Password: dari input              │
   │    - Metadata: name, role, store_id    │
   │    - is_active: true (otomatis)        │
   │                                        │
   │ 2. Create Employee Record              │
   │    - id: dari Auth user ID             │
   │    - username, name, phone, role       │
   │    - is_active: true (otomatis)        │
   └─────────────────────────────────────────┘

   UPDATE EMPLOYEE:
   ┌─────────────────────────────────────────┐
   │ 1. Update Employee Record              │
   │    - username, name, phone, role       │
   │    - is_active                         │
   │                                        │
   │ 2. Update Auth User Metadata           │
   │    - name, role, store_id, is_active   │
   │                                        │
   │ 3. Update Password (jika diisi)        │
   │    - Supabase Auth Admin API           │
   │                                        │
   │ 4. Update Email (jika username berubah)│
   │    - username@internal.pos             │
   └─────────────────────────────────────────┘

   LOGIN WITH STATUS CHECK:
   ┌─────────────────────────────────────────┐
   │ 1. Sign in with password               │
   │    - Email: username@internal.pos      │
   │    - Password: dari input              │
   │                                        │
   │ 2. Check user metadata                 │
   │    - is_active = true/false?           │
   │                                        │
   │ 3. If is_active = false:               │
   │    - Sign out immediately              │
   │    - Show error toast                  │
   │    - Return { success: false }         │
   │                                        │
   │ 4. If is_active = true:                │
   │    - Continue login                    │
   │    - Set user state                    │
   │    - Return { success: true }          │
   └─────────────────────────────────────────┘
