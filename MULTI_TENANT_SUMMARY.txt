┌──────────────────────────────────────────────────────────────────────────────┐
│ HIERARKI SISTEM                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

   Developer
       ↓
   Owner (Manual via Supabase Dashboard)
       ↓
   Stores (Via Web App)
       ↓
   Employees: Admin/Kasir (Via Web App, tied to Store)
       ↓
   Data: Products, Sales, etc (Isolated by store_id)

┌──────────────────────────────────────────────────────────────────────────────┐
│ YANG SUDAH BENAR ✅                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

   1. Database Schema ✅
      - stores table dengan RLS
      - employees table dengan store_id dan RLS
      - Semua data tables punya store_id

   2. Frontend Code ✅
      - employeesService.ts mengirim store_id saat create
      - AuthContext.tsx cek is_active saat login
      - Employees.tsx hanya Owner yang bisa CRUD

   3. Auth Flow ✅
      - Owner: No store_id, akses semua stores
      - Admin/Kasir: Punya store_id, locked ke 1 store

┌──────────────────────────────────────────────────────────────────────────────┐
│ FLOW YANG BENAR                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

   1. Developer → Owner
      ────────────────────────────────────────
      - Buat akun Owner manual di Supabase Dashboard
      - Set metadata: { "role": "owner", "name": "Owner Name" }
      - NO store_id untuk Owner

   2. Owner → Stores
      ────────────────────────────────────────
      - Owner login ke web app
      - Buka "Pengaturan" → "Toko"
      - Klik "Tambah Toko"
      - Isi nama, alamat, telepon
      - Store dibuat dengan id auto-increment

   3. Owner → Employees
      ────────────────────────────────────────
      - Owner pilih Store yang aktif
      - Buka "SDM" → "Manajemen Karyawan"
      - Klik "Tambah Karyawan"
      - Isi username, password, nama, role
      - System otomatis:
        * Buat Auth user dengan metadata.store_id
        * Buat record di employees dengan store_id
        * store_id diambil dari Store yang aktif

   4. Employees → Data
      ────────────────────────────────────────
      - Employee login
      - Hanya bisa akses data dari store mereka
      - RLS policies filter by store_id
      - Tidak bisa lihat data store lain

┌──────────────────────────────────────────────────────────────────────────────┐
│ SECURITY MATRIX                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

   ┌─────────┬────────────┬────────────┬──────────────────────┐
   │ Role    │ Stores     │ Employees  │ Data (Products, etc) │
   ├─────────┼────────────┼────────────┼──────────────────────┤
   │ Owner   │ CRUD All   │ CRUD All   │ CRUD All Stores      │
   │ Admin   │ Read All   │ Read Own   │ CRUD Own Store Only  │
   │ Kasir   │ Read All   │ Read Own   │ CRUD Own Store Only  │
   └─────────┴────────────┴────────────┴──────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ CONTOH: CREATE EMPLOYEE                                                      │
└──────────────────────────────────────────────────────────────────────────────┘

   Owner Action:
   ────────────────────────────────────────
   1. Pilih Store: "Toko Berkah - Cabang A" (id: 1)
   2. Klik "Tambah Karyawan"
   3. Isi form:
      - Username: kasir1
      - Password: kasir123
      - Nama: Siti Kasir
      - Role: Kasir

   Backend Process:
   ────────────────────────────────────────
   1. Create Auth User:
      email: kasir1@internal.pos
      password: kasir123
      metadata: {
        name: "Siti Kasir",
        role: "cashier",
        store_id: 1,  ← From active store
        is_active: true
      }

   2. Create Employee Record:
      INSERT INTO employees (
        id,        -- Auth user UUID
        store_id,  -- 1 (same as metadata)
        username,  -- kasir1
        name,      -- Siti Kasir
        role,      -- cashier
        is_active  -- true
      )

   Result:
   ────────────────────────────────────────
   ✅ Kasir1 bisa login
   ✅ Kasir1 locked ke Store 1
   ✅ Kasir1 hanya bisa akses data Store 1
